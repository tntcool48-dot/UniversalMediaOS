# Archive Movie/TV file identity — October 11, 2026

The Archive adapter attached item-level identity evidence to whichever video its file ranking selected. That ranking preferred original uploads, then MP4, then size. It could consequently certify an original MP4 trailer instead of the full film, or stamp item S1E1 onto an explicitly named S1E2/S2E1 file. The [official metadata API](https://archive.org/developers/md-read.html) returns item metadata and a separate file list; this repair checks the selected file's known contradictions before reusing the item evidence.

The production selector now excludes explicit supplemental labels such as trailer, teaser, preview and clip, including component folder labels. It removes the independently observed work title before interpreting these labels, preserving a feature whose own title contains “Trailer.” It also rejects explicit file season/episode claims that conflict with the observed item unit, and episodic component files for feature items. Decimal/range units cannot truncate to one integer. Compact `SxxEyy`, small-season `1x02` and descriptive season/episode labels remain bounded; ordinary `720x480` resolution does not become an episode.

This filters known contradictions rather than inventing file identity. Unlabelled files retain the existing provider-item evidence path; a generic filename does not establish the full cut, duration or spoken audio. Item IDs/title/year/form/rights, requested unit, transport validation, provider ordering, audio-unknown states and temporary ownership remain unchanged.
