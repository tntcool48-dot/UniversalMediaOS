# Anime Watch via download checkpoint — 2026-09-30

The Anime detail page now offers **Stream episode**, **Watch via download**, and **Season Download** as separate actions. Watch via download uses the existing Nyaa/AnimeTosho RSS feeds and embedded MonoTorrent; it requires no new key or provider picker. The permanent season queue is unchanged.

The temporary path checks the series and explicit season, reads torrent metadata, and accepts exactly one video file bearing the requested episode number. It sets all other torrent files to Do Not Download, except matching small caption sidecars. It bounds metadata and transfer time, file size, free disk space, and stalled transfers. Completed files must have readable video and audio according to `ffprobe`. The native player receives the local file and matching sidecar captions. Dub candidates need an explicit Dub or dual-audio label; when the audio track lacks an English language tag, the player says the language is unverified.

Each player tab owns a lease on the app's `TemporaryWatch` folder. Reopening the same catalog episode and audio mode shares the completed file while both tabs are open. Closing the last tab releases the native player before deleting that owned directory. Cancellation deletes partial data. At startup, the service removes abandoned GUID job directories while leaving directories locked by another running instance alone. A live check exposed that an interrupted deletion could remove the marker first and strand the video; cleanup now identifies jobs by their dedicated root and GUID name instead.

Verification: 101 selected C# tests passed, including 16 focused temporary-watch cases. A live Nyaa Frieren S2 episode 1 torrent exposed the exact file, progressed at roughly 11 MiB/s, and produced a 1,469,161,090-byte finished file. `ffprobe` found 24 minutes of H.264 video, Japanese AAC audio and English ASS subtitles; `ffmpeg` decoded video and audio at five minutes. A separate cancellation at 64% left zero job directories. Restart cleanup removed the full completed file left by an earlier abrupt process exit. The final implementation builds with no warnings or errors.
