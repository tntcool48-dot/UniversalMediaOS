# Native captions and requested audio — September 28, 2026

The final build played the real Frieren episode stream in the native player with visible English captions. Caption handoff and the reproduced wrong-Dub rejection are implemented. Actual English Dub and the broader anime acceptance matrix remain open.

## Changes

Python captures subtitle files from video tracks, JWPlayer/video.js configuration, source JSON and network requests. Tracks carry their own language/label, cookie, referrer and headers through the C# protocol, router, player messages and adjacent-episode results. Native media attaches subtitle slaves, prefers English, forwards tracks through retry/quality changes and releases owned caption sessions when media changes or closes. Caption responses have a ten-second body deadline, a 4 MiB limit and timed-text validation. HLS quality selection retains the master audio/subtitle groups.

Dub validation uses bounded TS/MP4 audio metadata or a validated English HLS audio rendition in every extraction stage and the native C# handoff. Japanese-only, unknown and null language metadata do not count as verified English. Controls now read their parent audio group, keep the selected Sub/Dub group and rotate current servers after unavailable files. No static anime provider selector, seed domain, new key or storage migration was added.

Live testing found two additional causes of native failure. Caption requests used the full iframe referrer while the browser's captured media request used the player origin. The original request returned HTTP 403; replaying the captured referrer returned 17,066 bytes of actual English WebVTT with HTTP 200. DOM/config caption fallback now uses only captured referrer/origin, retaining caption-specific overrides and excluding media cookies/authorization. Page cookies are not copied to a different caption origin.

Video crossed from the playlist host to another CDN. The proxy dropped its page context there. It now retains origin-only referrer/origin while keeping cookies, authorization, custom tokens and query/fragment credentials on their original host. The existing credential-boundary regression verifies that separation. The CDN also labels consecutive valid TS segments `image/jpeg`, `text/html` and `application/javascript`. The second segment was falsely rejected, ending playback at about 4.3 seconds. Python and the proxy now inspect consecutive TS packet headers for those labels; actual HTML/JSON/image decoys remain rejected and buffered bytes are replayed intact.
