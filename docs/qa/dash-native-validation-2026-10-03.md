# Finite DASH source validation and native playback — October 3, 2026

## Actual problem and repair

Python rejected all MPDs because XML and payload size alone do not establish media. Authenticated native MPDs also used raw relay, breaking relative resource URLs and captured header context. Source replacement did not release media proxy sessions consistently.

Python now qualifies a bounded, static, unprotected, single-period MP4 template manifest by checking its schedule, every selected resource location, and actual initialization plus first media bytes for the highest video and retained audio groups. Redirects, response size, content-range, truncated bodies and deadlines are checked. It supplies the captured DASH content type for extensionless source handoff. **This does not certify film/episode identity or spoken audio:** independent matching remains required, and the returned audio-language proof stays empty.

The native proxy rebuilds selected resources into an explicit finite MPD through their owning session. Initialization/media bodies use public-network and captured-origin header rules, size/deadline/prefix checks. Resource references never send provider XML directly to LibVLC. Native byte-range SegmentLists are conservatively refused; the existing download path supports its qualified range formats. Source replacement/close releases only that player's sessions, retaining its prepared session during same-source reload and leaving other players independent.

The first actual public sample still failed before its first frame despite reading a 193.680-second duration. A direct LibVLC check failed identically. Its version-1 MP4 `mvhd` uses the unsigned unknown-duration sentinel; [LibVLC 3's MP4 parser](https://raw.githubusercontent.com/videolan/vlc/3.0.x/modules/demux/mp4/mp4.c) rejects that value. In initialization bytes of already validated finite DASH, the proxy now replaces only this eight-byte sentinel with zero, preserving box length, timescale, all other bytes and fragment timestamps. The MPD still supplies the finite duration. Malformed, missing, zero-timescale and excessive initialization headers fail closed. Known finite duration fields remain untouched.
