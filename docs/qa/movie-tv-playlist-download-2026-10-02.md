## Problem and implementation

The actual TVmaze Breaking Bad S2E1 detail page resolved an independently matched native HLS source, but its source card offered only External and Stream. Both the viewmodel and download service restricted Watch via download to single video files. The temporary action now accepts finite HLS media while the permanent single-file download action retains its current contract. DASH and season downloads remain unfinished.

The downloader saves bounded manifests and their selected rendition, required audio groups, initialization files, AES-128 identity keys and media segments inside the existing GUID job. A previously checked rendition must still be advertised. Only completed leaf playlists with a finite duration are accepted; live, cyclic, unsupported protected or incomplete sources fail before handoff. The original work/season/episode context and source matching remain unchanged.

Requests use public-network connection validation, bounded redirects, a 20-second header/manifest deadline and two-minute body inactivity deadlines. The existing captured-header rules keep credentials on their origin and retain only public page context on another CDN. The transfer keeps the existing two-hour operation limit, configured byte maximum and one-GiB free-space reserve. FFmpeg reads the completed local assets with only file/crypto protocols, copies the selected video and audio tracks into a short MKV filename, and checks output duration against the finite playlist. Assembly has a ten-minute deadline and two-minute inactivity limit; cancellation kills the owned process. Successfully saved timed caption files accompany the native handoff and share its final-owner lease. Optional unavailable captions are omitted honestly.

The implementation uses the installed FFmpeg runtime and its documented [HLS options](https://ffmpeg.org/ffmpeg-formats.html#hls) and [protocol whitelist](https://ffmpeg.org/ffmpeg-protocols.html#Protocol-Options). No new dependency, default catalog provider, static picker or build copy was added.
